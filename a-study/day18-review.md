# 第18天：验收、复盘与下一阶段导航

今天只解决一个核心问题：

> 如何用运行证据证明第一轮学习已经形成完整蓝图，并把下一阶段交给真实项目问题驱动？

建议投入 **120分钟**。今天不学习新机制，只验收、修正和整理产物。

## 今日定位

- 所属层：学习闭环与项目交付
- 解决问题：章节看完后只有“好像懂了”，没有可验证能力和后续方向
- 接入位置：第一轮课程结束与项目迭代开始之间
- 重要程度：核心
- 今日深度：产出README、架构图、演示记录和问题清单；不补所有细节

## 今日可见成果

1. 一张完整Agent Harness架构图
2. 一个能重复运行的本地代码库分析Agent
3. README包含用途、架构、配置、运行、验收和限制
4. 正常与失败场景都有实际运行记录
5. 一份按重要程度排序的问题清单
6. 明确下一阶段只深挖哪三个主题

## 时间安排

### 0～20分钟：闭卷画蓝图

不要打开课程文档，画出：

```text
Model
└── Harness
    ├── Loop / Messages / Tool Results
    ├── Tools / Permission / Hooks / MCP
    ├── Todo / Task / Memory / Context
    ├── Subagent / Team
    └── Background / Cron / Workflow / Goal
```

给每个组件标记：核心、增强或高级，以及它接在Loop的哪个位置。

今天的所有权动作：先独立完成架构图，再对照源码纠错，不能让Codex直接替你生成第一版。

### 20～40分钟：做机制口述验收

每项限时2分钟：

1. Agent Loop为什么能连续调用工具
2. Permission与Hook分别负责什么
3. Context与Memory的区别
4. Subagent与Team的区别
5. MCP怎样动态加入工具
6. Background与Cron的区别
7. Workflow与Goal分别控制什么

说不清的内容只加入问题清单，不立即重学整章。

### 40～65分钟：重复运行项目正常场景

重新启动昨天的Agent，不改代码，让它分析另一个真实问题：

```text
s14连接MCP Server后，新工具为什么下一轮才出现？请给出代码依据。
```

保存运行命令、关键工具调用和最终回答摘要到README。

### 65～85分钟：运行失败与安全场景

验证：

- 工作目录越界
- 不存在的文件
- 空搜索结果
- 最大轮数停止
- 缺少`OPENAI_MODEL_ID`时的中文配置错误

只修阻碍验收的Bug，不新增功能。

### 85～105分钟：完善README

README只保留：

```text
项目解决什么问题
最小架构图
环境变量和运行命令
两个演示输入
安全边界
已知限制
下一步
```

删除学习日记式长文和无法证明的功能描述。

### 105～115分钟：形成问题清单

按三类整理：

```text
阻碍项目运行：立即解决
影响求职核心能力：未来两周解决
只有遇到真实需求才需要：暂不处理
```

候选重点只能选三个，例如：FastAPI接口、RAG、评测与可观测性。

### 115～120分钟：最终复述

用三分钟介绍项目，用两分钟解释完整工具调用数据流。录音或直接讲给自己听，不写长稿。

## Codex任务提示词

```text
请审查my-code-agent是否满足README中的现有验收标准。

WORKDIR路径边界、最大轮数、中文错误和最终证据格式。

先按严重程度列出实际问题和文件位置；只修复会导致验收失败的问题。
不要新增功能、依赖、框架或抽象。修复后运行py_compile和已有离线检查，
并给出一组正常场景与一组失败场景的运行命令。
```

## 运行实验

### 正常场景

提出一个必须搜索两个文件才能回答的问题。最终回答必须列出证据文件，并明确无法确认的部分。

### 失败或边界场景

请求读取工作目录之外的敏感路径。预期明确拒绝，且随后仍能处理一个正常问题。

观察：工具调用顺序、错误是否回填、循环是否恢复、结论是否有证据。

安全要求：不展示真实密钥；不访问项目外隐私文件；不为了演示临时关闭路径限制。

## 验收标准

- 不看源码能画出Harness完整蓝图
- 项目正常、失败和停止场景全部通过
- README中的描述都能由代码或运行结果证明
- 能在5分钟内介绍项目和核心数据流
- 下一阶段只保留三个有明确用途的学习主题

今日学习验收问答：

1. Agent与普通LLM调用最根本的区别是什么？
2. 哪些状态保存在消息历史之外，为什么？
3. 外部事件通过哪些路径重新进入Agent Loop？
4. 哪些机制是你当前项目真正需要的，哪些只是知道定位？
5. 如果面试官要求增加RAG，你会把它接在Harness的什么位置，先验证什么？
