今天只解决一个核心问题：

## 今日定位

- 所属层：完整Agent Harness运行时

- 接入位置：以`agent_loop()`为核心，调用前准备上下文和工具池，调用后执行工具、处理恢复并接收外部事件
- 重要程度：核心整合
- 今日深度：能够从任一行为定位到所属模块和接入点；不掌握所有边界实现

## 数据流

```text
用户输入
→ UserPrompt Hook
→ 加载Skill/Memory并准备Context
→ 收集Background/Cron/Team事件
→ 动态组装System和Tool Pool
→ Responses API
→ 保存全部response.output
→ Permission/Hook/Tool Handler
→ function_call_output回填
→ 压缩、重试或下一轮
→ Stop Hook
→ Transcript与Memory收尾
→ 最终回答
```
